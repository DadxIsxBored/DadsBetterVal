# DadsBetterVal

One configurable Valheim plugin containing area repair, safe inventory recycling and reclaiming, a game clock, improved processing machines, and unrestricted building. Frost Kiln input capacity and processing speed have separate controls.

Use the native crafting-panel `Reclaim` tab, or open inventory and press `Delete` over an unequipped item, to reclaim it. Hold Left Shift while using a supported furnace or processing machine for quick insertion. Every feature and value is configurable in `com.dadisbored.dadsbetterval.cfg`.
